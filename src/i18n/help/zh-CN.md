# Plainpad 帮助

在浏览器里使用的 Notepad++ 风格编辑器。这个标签页可以直接关掉，
需要时从“窗口 > 帮助”再打开。

## 拆分视图与比较

- “视图 > 拆分视图”打开第二视图，可以并排查看两个标签页，或同一个文件的两个位置。
  两边编辑同一份文档时内容实时同步。
- “工具 > 比较两个标签页”逐行比较：黄色是修改、红色是左边删掉、绿色是右边新增，
  斜线区块是为了对齐补上的空白。编辑时自动重新比较，↑↓ 跳到上一个 / 下一个差异。

## Markdown 预览

按工具栏的 M↓ 按钮（或 ⌃⇧M），右侧会显示当前标签页的 Markdown 预览，边输入边更新，
滚动会与编辑器同步。在预览中双击任一段落，编辑器会跳到那段源码。
代码块会按标注的语言着色（例如 ```sql、```csharp）。
“导出 HTML”会下载一份带样式的独立网页；“复制 HTML”只复制正文，方便粘贴到 Confluence 等地方。
预览里看不到外部或相对路径的图片（网页沙盒的限制），导出的 HTML 则可以正常显示。

数学公式用 LaTeX 语法：行内写 $E = mc^2$，独立一段写 $$ … $$ 或 ```math 代码块。
要输入金额的 $ 符号请写成 \$。
图表用 ```mermaid 代码块，支持流程图、时序图、甘特图、类图、ER 图、状态图等。
第一次用到时才会下载这两个组件，所以会慢一点。导出的 HTML 已经把图表和公式渲染好，不需要网络。

## Hex 编辑器

二进制文件和超过 25 MB 的文件会自动用 Hex 视图打开；也可以用“文件 > 以 Hex 打开”，
或按工具栏的六边形 Hex 按钮（⌃⇧H）把当前标签页在文本与 Hex 之间切换。

- 左边是地址，中间是十六进制字节，右边是文本。按 Tab 在两列之间切换。
- 直接输入就会修改：Hex 列输入 0–9、A–F，文本列输入字符。改过的字节会变成红色。
- 默认是改写模式，按 Insert 键或工具栏的“改写 / 插入”切换。Delete、Backspace 会删除字节。
- ⌘Z / ⇧⌘Z 撤销与重做；⌘C、⌘X、⌘V 在 Hex 列处理 hex 字符串，在文本列处理文本。
- 搜索可以查找 hex（?? 代表任意一个字节，例如 4D 5A ?? 00）或文本，⌘G / ⇧⌘G 查找下一个、上一个。
- “跳转到地址”（⌃G）接受 0x1F4、1F4h、500，以及 +100、-0x20 这类相对偏移。
- 右侧的数据解析会把光标位置的字节同时显示为各种整数、浮点数、time_t 与 FILETIME，可切换大小端。
- “Hex”菜单可以把选中范围复制为 hex 字符串、C / C++ 数组、C# 数组或 Base64。
- 大文件只会读取屏幕上需要的部分，GB 级的文件也能打开；编辑同样不需要把整个文件加载到内存。
- 保存时，.bin、.exe、.dll 这类扩展名无法直接下载，会询问要打包成 .zip（解压后就是原文件）或存为 .txt 再改名。
- 200 MB 以内的 Hex 标签页会保存在这个浏览器里，刷新后仍在；更大的不会保留。

## 书签

点击行号左侧的空白处，或按 ⌘F2。“搜索 > 书签”可以一次复制、剪切、删除书签行，
或只保留书签行。查找面板的“标记时加书签”会给所有匹配的行加上书签。

## 宏

按工具栏的红点开始录制，输入、方向键、删除以及“编辑”菜单的命令都会录进去，
再按一次停止。▶ 回放一次，▶▶ 可以运行指定次数或一直到文件末尾。
“宏 > 保存当前宏”可以命名保存。鼠标点击不会被录进去。

## 搜索

- 普通：按字面匹配。扩展：可用 \n \t \r \0 \xHH \uHHHH。
- 正则表达式：JavaScript 语法，^ 与 $ 按行匹配；替换可用 $1 或 \1。
- “全部列出”把结果列在下方面板，点击即可跳过去。
- “在文件中查找”需要先选择一个文件夹，文件只在你的浏览器里读取，不会上传。
  Chrome 会先弹出“要上传文件到这个网站吗”的确认，那是浏览器的固定用语。

## 保存与会话

- 所有标签页、书签和宏会自动保存在这个浏览器里（不会上传）。
- 保存时会弹出下载确认，网页无法直接覆盖硬盘上的原文件。
- 保存时沿用打开时的编码（例如 Big5 文件存回 Big5），换行符按右下角的设置（LF / CRLF / CR）。
  要更换编码请用“编码 > 保存时使用的编码”。有字符无法用原编码表示时，保存前会询问。
- 打开文件时自动识别 UTF-8、UTF-16、Big5、GB18030、Shift_JIS、EUC-KR 与 Windows-1252。
  识别错误时，可在“编码 > 以其他编码重新打开”中更换。

## 界面语言

“设置 > 界面语言”可以切换繁體中文、English、简体中文与 Tiếng Việt。页面会重新加载，标签页都会保留。
